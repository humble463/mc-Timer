MC 游戏时长 · 使用说明（新版：本地主页 + 主页里一键启动）
============================================================

【核心思路】
时长服务平时不用开，也不开机自启。
它会在你的 MC-Timer 文件夹里维护一个「PCL主页.xaml」。
PCL 主页选「本地主页」指向这个文件即可。
需要计时时，直接在 PCL 主页「游戏时长」卡片里点【一键启动服务】，
服务就在后台静默跑起来，把最新时长写进这个文件；
你回到 PCL 主页，看到的就是最新数字。

============================================================
第零步：装一次（拿到这个文件夹 / 换电脑 / 挪过位置后才需要）
============================================================
双击  MC-Timer\一键安装.cmd  ，按提示走完即可。它会：
  · 检查这台电脑有没有 Node.js（没有会告诉你去哪下载安装）
  · 自动找到你电脑上 PCL 的数据目录并记住
  · 把「一键启动服务」按钮的路径改成本机的实际路径
  · 顺带问你要不要清空上一份游玩数据（会先改名备份）
装完就不用再管它了。以后挪了文件夹、或者按钮报错了，重新双击一次就行。

============================================================
第一步：设置 PCL 主页（只需一次）
============================================================
PCL → 设置 → 个性化 → 自定义主页 → 选「本地主页」→
  选择文件：  MC-Timer\PCL主页.xaml
确认。以后 PCL 主页就是你自定义的那一套（欢迎语/寄语/网址/复制指令）。

============================================================
第二步：每次想计时时，只需在 PCL 里点一个按钮
============================================================
PCL 主页 →「游戏时长」卡片 → 点【一键启动服务】
  · 服务在后台启动，不弹黑窗口；
  · 点完等 1~2 秒，把 PCL 主页切走再切回来（或关掉重开），数字就是新的。
  · 想开自动计时 / 手动开始结束：点同卡片的【打开手动计时面板】。

============================================================
第三步：计时面板长什么样（从上到下）
============================================================
① 总累计（所有整合包加起来的时长，最上面最大那个数字；旁边会显示折合的游戏内天数）
② 自动计时开关（可选）
③ 各整合包游玩时间：PCL 里每个整合包自动占一行。
    每行显示一个数字：存档统计读出的真实游玩时长（时长旁会显示折合的
    Minecraft 游戏内天数，1 游戏日 = 20 分钟现实时间，显示整数天）。
    点一下那行可以展开操作：
      开始计时 / 结束计时（手动记某一段）
      记时长        （把这个包存挡里的历史时长当作起始累计，先建一条记录）
      设为自动计时目标
      计入总榜      （某行默认计入顶部“总累计”。点开那行点「☑ 计入总榜」即可让这一包
                    不计入总榜：顶部总累计和 PCL 主页都会跳过它，这一行仍保留、数字会变灰，
                    再点一下就改回计入。手动/自动新建的记录也都默认计入）
      ± 调整 / 重命名 / 删除记录 / 查看文件夹内容
      放进文件夹…  （把这一包收进文件夹分组里归类。可同时勾选多个文件夹，
                    同一个包能出现在几个文件夹里；分组只用于整理，不影响总累计
                    和任何时长。什么文件夹都不勾 = 回到「未分组」）
      批量删除      （每行最左边的小方框可勾选多条，再点上方出现的「删除所选记录」，
                    一次把这些记录连同累计一起删掉；自动找到、还没有计时记录的行没有
                    可删的东西，方框是灰的，勾不了）
    列表上方「＋ 新建文件夹」可以预先建一个空分组（之后展开某包放进去）；
    每个文件夹标题旁可重命名（✎）/删除（✕，只删分组、包都回到未分组），
    点一下文件夹标题即可收起 / 展开这一组。
    列表上方还有「文件夹排序」下拉：创建先后 / 名称（中文按拼音、英文按字母）/
      包数量（多→少）/ 自定义排序（切到它后每个文件夹标题旁出现 ▲▼ 小按钮，
      按你喜欢的顺序排，顺序会记住）；「未分组」始终在最后。
    列表上方还有「排序」下拉：默认 / 最近玩 / 游玩时长 /
      名字首字母（中文按拼音、英文按字母 A→Z）/
      自定义排序（切到它后每行会出现 ▲▼ 小按钮，按你喜欢的顺序排，顺序会记住）。
    排到「文件夹」分组视图时，各文件夹里和「未分组」里的行都按同一个排序规则排。
④ 游玩日历：顶部可直接输入「年份-月份」（如 2025-08）一键跳转，不用一直点前后箭头。
    蓝色 = 服务精确计时；橙色 ≈ = 按存档痕迹估算回填的旧日子；
    点某天能写备注；那几天有精确计时时，下面会列出当天每个时间段
    （几点到几点 · 哪个包 · 多久）。点「估算回填历史日期」可重新推算。
⑤ 读取整合包文件夹（见下）
⑥ 个性化（文字颜色 / 强调色 / 毛玻璃透明度 / 图标样式 / 背景图）

============================================================
第四步：时长怎么算的
============================================================
· 自动计时：打开「自动计时」开关，选一个兜底整合包。之后进游戏自动开始、
  退出自动结束并累加（检测 javaw 窗口）。
  它读 PCL 每次启动都会重写的 LatestLaunch.bat，认出这次启动的是哪个版本
  文件夹，把时长记到对应的那一条；如果这个整合包还没有记录，会自动新建一条
  （并把该包存档里的历史时长当起始累计）。分辨不出时才记到你选的那个兜底包。
· 手动计时：展开某包点「开始计时」，玩完点「结束计时」；忘了开就「± 调整」补分钟。
· 日历上的“过去日期”怎么来的：Minecraft 的存档只记“总共玩过多久”，不记某天几点玩，
  服务没开以前的日子没法精确还原。日历会把它们按存档文件（level.dat / stats / region）
  的修改痕迹，把总时长摊回那些可能玩过的日子，标成橙色 ≈，一眼能分清哪些是估的。
  从你点「一键启动服务」开始的日子才是蓝色精确计时，还会带当天的时间段明细。
· 主榜每行的数字，取自两份时长里较大的那一份，避免重复累加：
  ① 存档统计——Minecraft 自己记的「你在这个世界里玩过多久」，PCL 不显示；
  ② 面板计时——你在面板里手动/自动记下的累计。
  点开一行，小字会把这「存档时长 / 面板计时」分别列出来，方便对账。
  总累计 = 每包这个最大数字加起来的和。

============================================================
第五步：两个小工具（可选）
============================================================
· 读取整合包文件夹：输入一个整合包文件夹路径（例如
  E:\mc\整合包\versions\落幕曲1\.minecraft\versions\落幕曲），读出 PCL 没有的信息：
    - 这个包在存档统计里一共玩过多长时间、最近玩是哪天；
    - 文件夹里每一部分占多大（mods、saves 存档、config、resourcepacks…），
      带条形图，最后给总占用；
    - 每个存档世界各占多大、各玩过多久。
  记不清路径？点输入框下方的「🔍 自动扫描全盘找存档」，它会遍历每个磁盘，
  把带存档（saves）的整合包 / .minecraft 目录都列出来（第一次约几十秒，
  之后 10 分钟内有缓存），点任意一个就自动填路径并读取。
  扫描结果每一行右边还有一个「＋ 加入总榜」小按钮：一键把扫到的游玩时长
  加进主榜；这个文件夹若本来就有记录，服务不会重复添加，会提示“已在主榜”。
  想把这些“读到的时长”也记进主榜：读取结果顶部有
  「＋ 把读到的 XX 带进主榜」（建一条记录、把存档历史当起始累计），
  或「＋ 从 0 开始累计」纯手动计时。这个文件夹若已有记录会显示出来。
  模组清单 PCL 自己会列，这里就不重复读了。读取只算大小、读时长，
  不会改动你任何文件。也可以在上方主榜某行点「查看文件夹内容 ↓」直达。

· 个性化（面板最底下）：可以改文字颜色、强调色（按钮 / 高亮 / 勾选的颜色）、
  毛玻璃透明度、图标样式（彩色图标 / 简洁文字），以及选电脑里一张图当
  网页背景、调压暗。这些只影响这个计时面板网页，数据都留在本机；PCL 主页的
  背景在 PCL「设置 → 个性化」里单独换，两边互不影响。

· 左侧快捷入口：计时面板页面左侧有一竖排小按钮（总累计 / 自动计时 /
  主榜 / 日历 / 读取 / 个性化），点一下就直接滚到那个板块，不用一直往下翻；
  跟着页面滚动，当前所在板块会高亮。

============================================================
怎么关服务（可选）
============================================================
在计时面板右上角点【关闭服务】即可（服务是后台无窗口运行的）。
不关也行——它很轻，关机自然就没了。

============================================================
文件夹里的东西
============================================================
  PCL主页.xaml        你在 PCL 里选的本地主页文件；「游戏时长」卡片由服务自动更新
  server.js           时长服务主程序（Node）
  install.js          一键安装脚本（由 一键安装.cmd 调用，不用自己开）
  一键安装.cmd         换电脑 / 挪过位置后双击一次，把路径调对
  pcl-custom-path.txt 记录你这台电脑上 PCL 数据目录的位置（由 一键安装 生成）
  我的游戏时长.html    计时面板网页（可从主页按钮打开）
  start-hidden.vbs    「一键启动服务」按钮实际调用的静默启动脚本
  启动计时服务.cmd     备用：想看到黑窗口时双击它（关闭窗口即停）
  mc-time.json        计时数据（自动生成，可复制当备份；面板右上角也能备份/恢复）

【重要提醒】
· 想改主页其它卡片（欢迎语、寄语、网址、复制指令那些）：
  直接编辑 MC-Timer\PCL主页.xaml 里对应的卡片即可，
  只有「游戏时长」那张会被服务覆盖，别动它的中间部分。
· 「一键启动服务」按钮里的路径是本机的绝对路径，由 一键安装.cmd 写进去。
  把文件夹挪到别处之后，按钮会找不到文件（报「系统找不到指定的文件」）。
  这时重新双击一次 一键安装.cmd 即可；应急也可以直接双击 启动计时服务.cmd——
  它按自己所在的位置启动，起来之后会自动把按钮路径改回正确的位置。
